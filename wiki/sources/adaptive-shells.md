## Summary

本文提出了一种自适应窄带渲染方法，用于高效神经辐射场（NeRF）渲染。核心思想是：多数场景最终由固体表面组成，可用单个采样点渲染；模糊区域（如毛发、植被）则需要体积渲染。方法扩展了NeuS，将全局核大小替换为随3D位置变化的局部核大小，自动适应场景复杂度。通过水平集演化从学习的SDF提取自适应壳——内边界（侵蚀）和外边界（膨胀），形成窄带区域。推理时，光线追踪与壳相交，仅在壳内区域采样，固体区域用单采样点。实验表明，该方法在保持高保真度的同时，显著提升了渲染速度（Shelly数据集262 FPS，DTU数据集157 FPS），并支持cage-based变形、动画和物理模拟等下游应用。

## Key Contributions

1. **空间变化核大小**：扩展NeuS，将全局核大小s替换为随3D位置变化的局部核大小s(x)，自动适应场景复杂度，在模糊区域使用宽核，固体区域使用窄核。
2. **显式壳提取**：通过水平集演化从学习的SDF提取自适应壳——内边界（侵蚀）和外边界（膨胀），形成窄带区域，宽度由局部核大小决定。
3. **窄带渲染**：光线追踪与壳相交，仅在壳内区域采样，固体区域用单采样点，显著减少采样数量（最多10倍），提升帧率（最多5倍）。
4. **两阶段训练**：第一阶段全体积训练+正则化；提取壳后第二阶段仅用颜色损失微调，提升视觉保真度。

## Method

### 整体思路

NeRF体积渲染需要大量采样点，效率低下。然而，多数场景最终由固体表面组成，可用单个采样点渲染。本文提出自适应窄带渲染：在固体区域用单采样点，模糊区域用体积渲染。方法扩展NeuS，引入空间变化核大小，自动适应场景复杂度。通过水平集演化提取自适应壳，形成窄带区域。推理时，光线追踪与壳相交，仅在壳内区域采样，大幅提升渲染效率。

![方法概述](https://arxiv.org/html//html/2311.10091/assets/x3.png)
*图3：方法概述。通过在显式薄壳内进行高效采样的体积渲染，实现高保真、高效的神经隐式场景重建。*

### 3.1 预备知识

NeRF将场景表示为体积辐射场，将3D点x和视角方向d映射到体积密度σ和视角相关颜色c。标准体积渲染公式为：

c(r) = ∫[τ_n, τ_f] exp[∫[τ_n, τ] -σ(r(z))dz] σ(r(τ)) c(r(τ), d) dτ

NeuS提出用学习的SDF f替代直接学习的密度σ，通过sigmoid映射转换：

σ = max(-dΦ_s/dτ(f) / Φ_s(f), 0)，Φ_s(f) = (1+exp(-f/s))^{-1}

其中s为全局核大小，控制密度的扩散程度。小s产生宽核（模糊密度），大s产生窄核（锐利表面）。

### 3.2 空间变化核大小

NeuS使用全局核大小，无法适应场景中不同区域的复杂度。本文将全局核大小s替换为随3D位置变化的局部核大小s(x)，网络输出变为(c, f, s) = NN_θ(x, d)。训练时加入正则化项L_s促进核大小场的平滑性：

L_s = (1/|X|) Σ_{x∈X} ||log[s(x)] - log[s(x+ N(0, ε²))]||₂

空间变化核大小自动适应场景内容：固体表面使用窄核，模糊区域使用宽核。

![水平集演化](https://arxiv.org/html//html/2311.10091/assets/x5.png)
*图4：在拟合初始SDF和空间变化核后，我们通过水平集流进行侵蚀和膨胀来提取自适应壳。为说明目的，自适应壳被放大；实际上它非常紧密地包围锐利表面。*

### 3.3 显式壳提取

自适应壳由两个显式三角网格表示：内边界（侵蚀）和外边界（膨胀）。宽度由局部核大小决定：大s产生厚壳（体积内容），小s产生薄壳（表面）。

提取过程：
1. 在规则网格顶点采样f和s字段
2. 对f应用水平集演化，产生侵蚀字段SDF_-和膨胀字段SDF_+
3. 通过marching cubes提取SDF_-=0和SDF_+=0水平集作为内外边界网格M_-和M_+

水平集演化方程：

∂f/∂t = -|∇f| (v(f₀, s) + λ_curv ∇·(∇f/|∇f|)) ω(f)

其中ω(f)为软衰减窗口函数，限制演化范围。

膨胀速度：v_dilate = β_d · σ(f₀, s)（当σ > σ_min）
侵蚀速度：v_erode = min(v_max, β_e / σ(f₀, s))

这些速度导致：小s区域（表面）演化距离短，形成薄壳；大s区域（体积）演化距离长，形成厚壳。

![字段可视化](https://arxiv.org/html//html/2311.10091/assets/x7.png)
*图5：给定从3.2节学习的核大小s和SDF f（顶部），我们对f应用侵蚀和膨胀流（底部中间和左侧）来提取窄带壳，在其中高效渲染（底部右侧）。*

### 3.4 窄带渲染

提取的自适应壳作为辅助加速数据结构，指导光线采样。对于每条光线，使用硬件加速光线追踪与壳相交，得到光线进入/退出壳的区间序列。在每个区间内均匀采样，采样数量由区间宽度w、目标采样间距δ_s和单采样阈值w_s决定：

采样数 = ceil(max(w - w_s, 0) / δ_s) + 1

当区间因光线击中内网格M_-而结束时，停止处理后续采样（表示固体内部）。否则处理区间直到光线退出场景或达到最大采样数N_max。

该过程可实现为：先生成所有区间内的所有采样点，然后执行单次批量MLP推理，提高吞吐量。对于表面，窄带采样通常只需一次硬件加速光线追踪加一次网络评估；对于模糊区域，仅在必要处密集采样。

![核大小对比](https://arxiv.org/html//html/2311.10091/assets/x10.png)
*图7：原始NeuS使用单一全局核大小s。在内容复杂的场景中，全局s值收敛到平均值，对体积部分太小，对锐利表面太大。我们的局部变化核大小适应场景，从而将锐利表面的采样数减少到单个，蕨类植物最多32个采样。NeuS使用恒定384个采样每像素。*

### 3.5 损失与训练

训练分两阶段：

**第一阶段**：全体积训练，最小化损失函数：

L = L_c + λ_e L_e + λ_s L_s + λ_n L_n

其中λ_c=1, λ_e=0.1, λ_n=0.1, λ_s=0.01。

- L_c：像素级颜色损失
- L_e：Eikonal正则化，鼓励SDF为真实距离函数
- L_s：核大小场平滑正则化
- L_n：预测法线与SDF梯度法线的一致性损失

**第二阶段**：提取壳后，仅用颜色损失L_c微调，禁用正则化。这使网络专注于拟合视觉外观，提升视觉保真度。

## Training

- **第一阶段**：全体积训练，使用多分辨率哈希编码（14级，每级2^22特征），几何网络输出SDF值f、核大小s、几何特征f_geo和法线n。训练50k迭代。
- **第二阶段**：提取自适应壳后，在窄带区域内微调，仅使用颜色损失。训练10k迭代。
- **硬件**：单张RTX 4090 GPU。
- **优化器**：Adam，学习率从5e-4衰减到1e-5。
- **超参数**：膨胀β_d=0.5，侵蚀β_e=0.01，窗口宽度ζ=0.1（膨胀）/0.05（侵蚀）。

## Related Work Analysis

### Neural Radiance Fields (NeRFs)

NeRF使用神经网络表示场景的体积辐射场，通过体积渲染合成新视角。后续工作改进了质量（MipNeRF, MipNeRF 360）和效率（Instant NGP）。本文方法与NeRF互补，通过自适应采样加速渲染。

### 隐式表面表示

NeuS和VolSDF提出用SDF和全局核大小替代直接密度学习，改善表面重建质量。本文扩展NeuS，引入空间变化核大小，自动适应场景复杂度。

### 加速神经体积渲染

多种方法加速NeRF：局部特征场（Instant NGP）、烘焙到代理几何（MobileNeRF, BakedSDF）、预计算网格（MeRF）。本文方法与这些互补，通过自适应采样减少计算量，同时保持体积表示的灵活性。

### 相关工作对比

- **MobileNeRF/BakedSDF**：将外观约束到表面，牺牲质量。本文保留完整体积表示，保持近NeRF质量。
- **DuplexRF**：也提取显式壳，但直接从辐射场阈值提取，需要仔细选择阈值，壳不适应局部复杂度。
- **VMesh**：类似洞察，但使用额外体素网格标记体积区域，扩展性差。本文使用显式自适应壳，复杂度更低。

## Ablations

### 空间变化核 vs 固定核

在Shelly数据集上，空间变化核在所有指标上提升：
- PSNR: +0.5 dB
- SSIM: +0.01
- LPIPS: -0.01

### 自适应壳 vs 固定阈值壳

固定SDF阈值提取壳需要在模糊表面表示（阈值0.02）和增加采样数（阈值0.05）之间妥协。自适应壳自动适应局部复杂度，质量更高，采样数更低。

### 保持正则化 vs 微调时禁用

提取壳后禁用正则化，使网络专注于拟合视觉外观：
- PSNR: +0.2 dB
- SSIM: +0.005
- LPIPS: -0.005

### 采样数影响

采样数不足时（0.25×-1×），PSNR敏感；采样数充足时（1×-4×），质量饱和。运行时间与采样数近似线性关系。

## Limitations

1. **薄结构捕获**：不能保证捕获薄结构——如果自适应壳遗漏几何区域，微调时无法恢复，导致重建缺失。
2. **MipNeRF360伪影**：在MipNeRF360场景中，复杂背景可能导致伪影，因为方法未专门处理背景。
3. **训练效率**：第一阶段训练与Li et al. (2023)类似，未针对训练效率优化。
4. **背景处理**：对无界场景的背景表示不如专门方法（如MipNeRF 360）。

## Connections

- **NeuS (Wang et al., 2021)**：本文直接扩展NeuS，将全局核大小替换为空间变化核大小。
- **Instant NGP (Müller et al., 2022)**：本文的主要效率基线，通过自适应采样显著超越其性能。
- **Volumetric Surfaces**：引用本文，区别在于本文使用体积渲染和单个空间变化SDF核，Volumetric Surfaces使用多个SDF和光栅化。
- **cage-based变形**：提取的外网格M_+可直接用于cage-based变形、动画和物理模拟。

## Contradictions

1. **体积 vs 表面**：本文主张体积渲染对模糊区域必要，但固体区域用单采样点（接近表面渲染）。这看似矛盾，但自适应壳实现了平滑过渡。
2. **效率 vs 质量**：通常效率和质量折衷，但本文通过自适应采样同时提升两者：固体区域减少采样（效率），模糊区域增加采样（质量）。
3. **显式 vs 隐式**：使用显式壳（三角网格）加速隐式表示（神经场），结合了两者优势。
4. **全局 vs 局部**：全局核大小无法适应场景复杂度，局部核大小自动适应，看似更复杂但实际更高效。
