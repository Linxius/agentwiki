## Summary

本文提出自适应窄带渲染方法（Adaptive Shells），用于高效[[Neural Radiance Fields|NeRF]]渲染。核心洞察：大多数场景由固体表面组成（可单采样点渲染），但模糊区域（毛发、植被）需体积渲染。方法扩展[[NeuS]]，将全局核大小替换为随3D位置变化的局部核大小，自动适应场景复杂度。通过水平集演化从学习的[[SDF]]提取自适应壳——内边界（侵蚀）和外边界（膨胀），形成窄带区域。推理时用硬件加速光线追踪与壳相交，仅在壳内区域采样。在RTX 4090上实现40-300 FPS（1080p），同时保持高保真度，并支持cage-based变形、动画和物理模拟。

## Key Contributions

1. **空间变化核大小**：扩展[[NeuS]]，将全局核大小s替换为随3D位置变化的局部核大小s(x)，自动适应场景复杂度——模糊区域用宽核，固体区域用窄核，无需额外监督
2. **自适应窄带壳提取**：通过水平集演化从学习的[[SDF]]提取自适应壳（内边界侵蚀+外边界膨胀），形成宽度由局部核大小驱动的窄带区域，创新性地解决了直接SDF阈值提取的噪声问题
3. **窄带渲染管线**：硬件加速光线追踪壳相交，仅在壳内均匀采样：固体区域w<w_s时单采样点，模糊区域多采样（最多32），单次批量MLP推理提升吞吐量
4. **两阶段训练策略**：第一阶段全体积训练（颜色+L_eikonal+L_smooth+L_normal）；提取壳后第二阶段仅用颜色损失微调，禁用几何正则化，提升视觉保真度
5. **下游应用**：外壳网格M+可直接用于cage-based变形、动画和物理模拟（弹性有限元仿真）

## Method

*图3：方法概述。通过在显式薄壳内进行高效采样的体积渲染，实现高保真、高效的神经隐式场景重建。*

### 整体思路

[[Neural Radiance Fields|NeRF]]体积渲染沿光线密集采样，计算昂贵。但真实场景大多由固体表面构成（1个采样点即可准确渲染），仅少部分区域（毛发、草地、树叶等）需要体积渲染。本文提出两级自适应：首先让网络学习一个**空间变化的核大小**，自动区分"表面"和"体积"区域；然后根据这个核大小提取一个**自适应窄带壳**，将神经场的计算约束在壳内。固体区域壳极薄（≈单采样），模糊区域壳较宽（体积渲染）。推理时先用光线追踪跳过空区域，再在壳内均匀采样。

### 空间变化核大小 (Spatially-Varying Kernel)

[[NeuS]]将[[SDF]] f 通过sigmoid映射为体积密度σ：

σ = max(-dΦ_s/dτ(f) / Φ_s(f), 0), Φ_s(f) = (1+exp(-f/s))^{-1}

其中s是全局核大小——小s→宽核(模糊密度)，大s→窄核(锐利密度)。但场景中固体和模糊区域并存时，全局s只能取折中值。

本文改为让网络输出(c, f, s) = NN_θ(x, d)，s(x)随3D位置变化。训练时加入平滑正则化：

ℒ_s = (1/|𝒳|) Σ_{x∈𝒳} ||log[s(x)] - log[s(x+𝒩(0,ε²))]||₂

仅从颜色监督即可自动学习：固体表面→窄核(s→0)，模糊区域→宽核(s较大)。这独立于壳提取已能提升重建质量。

### 显式壳提取 (Explicit Shell Extraction)

自适应壳由两个三角网格表示：外网格M+（膨胀）和内网格M-（侵蚀），壳宽由局部核大小s(x)决定。

直接提取|f/s|<η不可行——远离f=0水平集时场变得有噪声。本文用**受约束的水平集演化**分两步：

**膨胀**（向外扩展）：速度正比于密度σ，填充所有有贡献区域
- v_dilate = β_d · σ(f₀,s) 当σ > σ_min
- ζ=0.1, λ_curv=0.01（曲面平滑正则化）

**侵蚀**（向内收缩）：速度反比于密度，高密度区域慢（精确保持表面），低密度区域快（快速穿透空区域）
- v_erode = min(v_max, β_e / σ(f₀,s))
- ζ=0.05, λ_curv=0（不需要平滑）

演化方程：∂f/∂t = -|∇f|(v(f₀,s) + λ_curv∇·(∇f/|∇f|)) ω(f)

其中ω(f)=½(1+cos(π clamp(f/ζ,-1,1)))为软衰减窗口。在前向欧拉50步后，用Marching Cubes提取两个水平集。

结果：小s→表面→短距离演化→薄壳；大s→体积→长距离演化→厚壳。

### 窄带渲染 (Narrow-Band Rendering)

1. 为M+和M-构建BVH加速结构（OptiX）
2. 每条光线追踪与两壳的交点，获得零或多个壳内区间
3. 对每个宽度为w的区间：
   - 若w < w_s（单采样阈值）：区间中心取1个采样点
   - 否则：采样数 = ceil(max(w-w_s,0)/δ_s) + 1
4. 光线遇到内网格M-时停止（固体内部）
5. 所有采样点批量送入MLP推理

关键优势：无需动态自适应采样或终止条件，适合GPU并行执行。表面区域往往只需1次光线追踪+1次网络评估。

## Training

**第一阶段**（全体积训练，50k迭代）：
- 多分辨率哈希编码：14级，每级2^22个2维特征，分辨率16³→8192³
- 几何网络：MLP 31→64→31，输出(f, 1/s, f_geo, n)
- 辐射网络：MLP 48→64→64→3，输入(γ(d), f_geo, n, x)，SH编码至4阶
- 损失：ℒ = ℒ_c + 0.1ℒ_e + 0.01ℒ_s + 0.1ℒ_n
  - ℒ_c：L1颜色损失
  - ℒ_e：[[Eikonal]]正则化||∇f||_2=1
  - ℒ_s：核大小场平滑正则化
  - ℒ_n：预测法线与有限差分SDF梯度的一致性

**第二阶段**（壳内微调，10k迭代）：
- 提取壳后，仅在壳内采样
- 仅使用ℒ_c（禁用所有几何正则化）
- 让网络全容量拟合视觉外观

- 优化器：Adam，lr从5e-4衰减到1e-5
- 硬件：单RTX 4090
- 推理实现：Dr.Jit + OptiX（自动核融合+硬件光线追踪）

## Related Work Analysis

### Neural Radiance Fields (NeRFs)
[[Neural Radiance Fields|NeRF]]开创了神经体积渲染范式。后续工作包括质量改进（[[MipNeRF]], MipNeRF 360）和效率提升（[[Instant NGP]], Plenoxels）。本文独立于这些工作，通过自适应采样加速，可与这些方法互补。

### 隐式表面表示
[[NeuS]]和[[VolSDF]]将密度分解为[[SDF]]+全局核大小。本文核心创新是将全局核扩展为空间变化核，同时保留[[Eikonal]]正则化的几何约束。

### 加速神经体积渲染
- [[Instant NGP]]（哈希编码+空域跳过）：仍需多采样，网格分辨率扩展性差
- [[MobileNeRF]]/[[BakedSDF]]：烘焙到代理几何→牺牲模糊区域质量
- DuplexRF：也提取壳，但用辐射场直接阈值→噪声大、需人工调参
- VMesh：用额外体素网格→扩展性差
- MeRF：预计算到离散网格→完全正交，可组合

本文方法在"保留体积表示灵活性"和"实时渲染效率"之间取得独特平衡。

## Ablations

1. **空间变化核 vs 全局核**（Shelly数据集）：PSNR +0.5, SSIM +0.01, LPIPS -0.01。独立贡献，无需壳提取。
2. **自适应壳 vs 固定阈值壳**：固定阈值需在"覆盖模糊几何"和"减少采样"间折中；自适应壳自动平衡。
3. **第二阶段禁用正则化**：PSNR +0.2, SSIM +0.005, LPIPS -0.005。
4. **采样数对质量的影响**：0.25×-1×时PSNR敏感，1×-4×时饱和；简单场景（Kitten/Fernvase）因固定开销进一步降低采样数不减少运行时间。

## Limitations

1. **薄结构丢失**：若自适应壳遗漏薄几何区域，微调阶段无法恢复——这是最根本的局限。作者提出未来用迭代式"调优→自适应壳→再调优"解决。
2. **MipNeRF360场景伪影**：复杂背景处理不佳，浮空几何和背景分辨率不足。
3. **训练未优化**：第一阶段类似Neuralangelo，未采用推理端的性能优化。
4. **无界场景背景**：对360°无界场景的背景表示不如专门方法（Mip-NeRF 360）。
5. **依赖精确初始SDF**：壳质量高度依赖第一阶段SDF拟合质量。

## Connections

- [[NeuS]] — 直接扩展，将全局核→空间变化核
- [[Instant NGP]] — 主要效率基线，同样使用哈希编码做特征场
- [[Neural Radiance Fields]] — 基本范式，本文在此框架上加速
- [[Signed Distance Function]] — 核心几何表示（SDF→σ映射）
- [[Volumetric Surfaces]] — 相关方向：多层网格表示模糊几何，本文用单个SDF+自适应核

## Contradictions

- 本文主张"显式壳+隐式场"混合比纯显式（[[MobileNeRF]]）或纯隐式（[[Instant NGP]]）都更优——这挑战了领域内"要么纯显式、要么纯隐式"的二分法
- 自适应壳使"减少采样=提升效率"不必然导致质量下降——在固体区域采样越少反而可能越准确（避免体渲染伪影），打破了效率-质量的传统折中关系
