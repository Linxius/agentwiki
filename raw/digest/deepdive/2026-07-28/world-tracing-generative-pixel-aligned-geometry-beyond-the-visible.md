# World Tracing: Generative Pixel-Aligned Geometry Beyond the Visible

## 论文概览（仅背景、贡献和指标，不要涉及方法细节）

1. **解决的问题** — 单张图像/单目视频的忠实且完整的3D几何重建，即同时恢复可见表面和被遮挡的背面/内部几何。
2. **现有方法不足** — 深度估计器（如DepthAnything、MoGe）只能恢复可见表面，超出首层被遮挡区域完全缺失；图像转3D生成模型（如TRELLIS、Zero-1-to-3）虽生成完整几何，但使用规范坐标系且丢弃像素级对齐，导致与输入图像的几何不对齐。
3. **本文贡献** — 提出 World Tracing (WT)，一种生成式像素对齐多层几何表示，对每像素预测有序6层3D点堆栈（第0层可见表面，第1-5层从前到后的被遮挡表面），统一了可见表面忠实重建和遮挡几何生成为同一相机空间张量。
4. **效果指标** — 在物体（Objaverse-XL）、场景（3D-FRONT等）、动态（ActionBench等）三个基准上，可见表面深度MAE达0.0149（MoGe-2为0.0261）、完整几何Chamfer距离L2达0.00194（TRELLIS.2为0.00717），均超越深度预测器和图生3D模型。

## 技术拆解（全部方法内容，这是报告主体）

### 1. World Tracing 多层几何表示 (Sec 3.1)

**输入/目的：** 输入一张 RGBA 图像 I ∈ R^{H×W×4}（RGB + alpha 前景/有效掩码），目标是对每像素预测完整且有序的多层3D几何。alpha 通道标记有效像素：物体模型用它分离前景，场景模型用它屏蔽天空等无穷远像素。

**原理：** 将问题重新定义为每像素的多层3D点预测。对每个像素 u，沿其对应相机射线预测 L 层有序的相机空间 3D 点。第0层是可见表面（与输入图像直接对齐），第1-5层是从前到后的被遮挡表面。这样可见表面重建和遮挡几何完成不再是两个独立输出，而是同一像素网格张量上的连续层。"忠实生成"（faithful generation）——忠实重建可见表面 + 合理生成不可见部分——成为同一输出。

**公式：** 预测张量 X ∈ R^{L×H×W×3}，其中
X[ℓ, u] = x^ℓ(u)
x^ℓ(u) 是光线通过像素 u 的第 ℓ 个从前到后交点的相机空间3D点。L=6（所有变体）。不需要输入相机内参——当需要下游使用时，可从预测的第0层点云通过闭式最小二乘拟合出 K。

**输出/效果：** 像素对齐的多层3D点云张量，保留完整的像素到3D对应关系（pixel-to-3D correspondence）。第0层受输入像素强约束，深层需要生成式补全。所有预测在输入像素网格上进行并表达在相机坐标系中，因此规范坐标系生成器通常丢弃的相机姿态信息和像素对应关系被自然地保留。

### 2. 深度填充策略 (Depth Filling) (Sec 3.1)

**输入/目的：** 传统深度剥离算法在后层产生稀疏像素——许多光线上的表面交点数小于 L。直接预测每层二值有效掩码会带来严重的类别不平衡（物体渲染中 L0 有效面积 8.14%，L5 仅 0.60%），使掩码头倾向于预测"无效"导致深层塌缩。而且坐标回归和可见性分类耦合在一起，产生冲突的训练信号。

**原理：** 不预测稀疏的有效掩码，而是将空交点前向填充（forward-fill），使所有光线在所有层都有稠密监督目标。即如果一个像素在某层没有真实交点，就从最近的更浅层复制已有的交点值。填充后形状不变（重复点不引入新几何），但所有有效光线在所有层都有了训练信号。

**公式：**
x^ℓ(u) ← x^{ℓ'}(u)，其中 ℓ' = max{ k < ℓ : x^k(u) 有效 }
即从最近的更浅有效层前向填充。设 ¯X 为填充后的稠密多层XYZ目标。

**输出/效果：** 每有效像素在所有6层都有监督信号，且训练目标变为纯粹的XYZ坐标回归（无需耦合可见性分类）。诊断实验表明，原本就有交点的深层像素与继承填充的像素误差水平接近，验证了填充作为有效稠密监督策略的合理性。这也使得同一流匹配损失可以联合训练所有层。

### 3. 尺度归一化 (Scale Normalization) (Sec 3.1)

**输入/目的：** 原始相机空间坐标在物体（小尺度）和场景（大尺度、跨样本深度范围差几个数量级）间差异极大，单一尺度无法同时处理。

**原理：** 对物体和场景使用不同的可逆归一化映射，但同一架构预测归一化张量，仅坐标变换不同。

**公式：**
- **物体 (z-score):** ˜X = (¯X - μ_dataset) / σ_dataset，使用数据集级每通道 z-score 标准化（将目标数据标准化到单位正态分布）
- **场景 (log-median):** 逐样本中位数归一化后接符号对数变换。深度在样本间可差几个数量级，通过中位数缩放后再做 signed log 保持在有界范围

**输出/效果：** 归一化坐标 ˜X 在同一值域内。推理时通过逆变换（逆z-score或逆对数中位数映射）恢复相机空间坐标。这些映射在深度上单调，因此保持了层的从前到后顺序，相邻层单调性惩罚也得以正确工作。

### 4. 流匹配目标 (Flow Matching Objective) (Sec 3.1)

**输入/目的：** 训练 WT-DiT 做条件生成，从高斯噪声逐步去噪到归一化多层XYZ目标。直接在坐标信号上做流匹配，而非在 VAE 潜空间上扩散。

**原理：** 使用 rectified flow（纠正流），在干净目标 x₀ 和纯噪声 x₁ 之间做线性插值。网络预测 x₀（干净端点参数化），而不是预测噪声或速度。训练时只在 alpha 有效区域的像素上计算损失。推理时从最大噪声开始，用20步 ODE 积分向 t=0 推进。

**公式：**
- 插值轨迹：x_t = (1 - t)x₀ + tx₁，其中 x₀ = ˜X，x₁ ~ N(0, I)，t ~ p_train(t)
- 端点损失：L_FM = E[A ⊙ || F_θ(x_t^net, t, f_I) - x₀ ||²₂]
  - A: alpha 有效掩码，广播到所有层和XYZ通道
  - f_I: MoGe 编码器输出的特征网格
  - x_t^net: 在无效像素处将带噪几何替换为最大高斯噪声，使网络学会忽略它们
- 推理流 ODE 速度：v_θ(x_t, t, f_I) = (x_t - F_θ(x_t^net, t, f_I)) / t
- 完整损失附加软相邻层单调性惩罚 L_mono：推动相邻层在归一化坐标空间中保持从前到后顺序

**输出/效果：** 网络直接输出干净多层XYZ预测 ˆx₀。整个框架不需要每层掩码、轮廓或可见性分类头。推理时20步 ODE 积分就能从纯噪声生成完整多层几何。

### 5. 混合噪声调度 (Layer-aware Training Noise Curriculum) (Sec 3.3)

**输入/目的：** 可见层（L0）和遮挡层（L1-L5）有非常不同的不确定性特征。L0 受输入图像强约束，更像重建目标；深层仅受间接约束，需要条件生成。单一扩散时间分布无法同时服务于这两个不同模式。

**原理：** 早期训练中，L0 从 plateaued logit-normal 分布采样（低噪声权重较高，侧重可见表面重建），L1-L5 从标准 logit-normal 分布采样（侧重生成）。等所有层稳定后，切换为所有层共享同一时间步，从两个调度的等权混合中采样。

**公式：** 混合调度 = 等权混合 plateaued logit-normal 和标准 logit-normal 分布。

**输出/效果：** 平衡可见表面重建和遮挡几何生成，L0的AbsRel和L1-L5的CD-L2均优于单独使用任一调度。表4显示 CD-L2：混合调度 L0=0.020，L1-L5=0.025，全部=0.024；plateaued logit-normal 分别为 0.021/0.033/0.031；标准 logit-normal 为 0.023/0.028/0.027。

### 6. WT-DiT 架构 — 总览 (Sec 3.2, Fig 2)

**输入/目的：** 将输入图像和带噪多层XYZ张量映射到干净 x₀ 预测。

**原理：** WT-DiT 是流匹配扩散 Transformer。使用冻结的 MoGe ViT-L 编码器提供像素对齐图像特征（仅训练来自最后几层的特征投影）。带噪多层XYZ在像素网格上 patch 化（patch=14×14）为几何 token。像素对齐融合（Pixel-aligned Fusion）在每个 (ℓ, u) 处将层 ℓ 的带噪几何与对应像素 u 的图像特征通道级拼接并投影到解码器宽度。解码器循环通过三层分解自注意力，最后由线性 patch 投影将每个 decoder token 映射到其 14×14 patch 的 XYZ，经 unpatchify 恢复完整多层图像网格。

**公式：** token 网格形状 (B, L, P, D)，其中 P = 网格 patch 数，D = 1536

**输出/效果：** 每 decoder token 对应一个 14×14 patch 的 3D 坐标。整个解码过程中图像证据和几何状态保持逐像素对应关系，无需单独的交叉注意力路径。约 1.7B 参数（~1.4B 可训练），48 个 pre-norm DiT 块。

### 7. 三层分解注意力 (Three-way Attention Factorization) (Sec 3.2)

**输入/目的：** L×P 个 token 上的完整自注意力缺乏结构且计算昂贵（L=6层，每层约P个patch）。需要一种高效的方式让 token 既在空间维度上通信、又在深度维度上交互。

**原理：** 解码器循环通过三种注意力形状，分别捕获不同的依赖关系：

1. **逐层注意力 (Layer-wise / Spatial Attention)：** 形状 (B·L, P, D)。每层作为独立 2D 图像做自注意力，使用 2D RoPE 位置编码在 (y, x) 空间坐标上。负责每层内部的几何连续性，即同一层中相邻空间位置的几何一致性。

2. **逐射线注意力 (Ray-wise / Depth Attention)：** 形状 (B·P, L, D)。同一像素位置的不同层沿深度（层）轴自注意力。强制执行深度排序（从前到后）和层间一致性，确保深层几何与可见表面在空间上一致。这是让单张图像产生连贯多层几何的关键——显式的射线轴防止深层漂移偏离可见表面。

3. **全局注意力 (Global Attention)：** 形状 (B, L·P, D)。所有 token 无结构地全局自注意力，恢复物体/场景级上下文。

**输出/效果：** 消融实验（Sec 4.3）验证了显式射线注意力是深层不漂移的关键。相比 VGGT 的帧/全局交替，WT 的显式射线轴让单一骨干网络从单张图像生成连贯的多层几何。

### 8. 层感知条件 (Layer-aware Conditioning) / Layer FiLM (Sec 3.2)

**输入/目的：** 每个 token 需要知道它属于哪一层以及当前扩散时间步，否则层排列对称性（所有浅层/深层 token 无法区分）会使训练不稳定。

**原理：** 使用 Layer FiLM（特征线性调制）注入层信息。每层有可学习的嵌入向量 e_ℓ (ℓ=0..5)，通过 MLP 映射到通道级缩放和偏置 (γ_ℓ, β_ℓ)。对 token h 应用：
h ← γ_ℓ ⊙ h + β_ℓ
扩散时间步 t 使用标准 AdaLN 零初始化调制，跨所有 token 共享。FiLM 打破层对称性而不需要可学习的加性位置 token。

**输出/效果：** 每个token被明确标记其层身份，否者对层索引的排列是等价的（permutation symmetric），训练会混叠。

---

### 9. 像素对齐融合 (Pixel-aligned Fusion) (Sec 3.2)

**输入/目的：** 将图像特征和几何状态结合起来，使几何预测保留细致的图像证据。

**原理：** 在输入解码器前，在每个 patch 位置 u，将（重复的）该像素的图像特征与层 ℓ 的带噪几何状态做通道级拼接，再投影到解码器宽度 D。这样在整个解码过程中图像证据和几何状态都保持逐像素对应关系（correspondence），无需单独的交叉注意力路径（无需 cross-attention）。

**公式：** token(ℓ, u) = Projection( concat[ image_feat(u), noisy_xyz(ℓ, u) ] )

**输出/效果：** 所有几何 token 从输入到输出都与对应的图像特征保持空间对齐。这与"全局潜编码器+分离生成器"的范式形成对比——后者在全局编码时会丢弃细粒度图像证据。

---

### 10. 时序注意力 (WT-D 动态模型) (Sec 3.2)

**输入/目的：** 从单帧静态模型微调为多帧动态模型，需要跨帧的一致性。

**原理：** 保持静态解码器结构不变，在每个全局注意力块后插入一个时序注意力块。时序块将 token 重整化为 (B·L·P, T, D)（T=16帧），沿时间轴做单层自注意力，使用 1D RoPE 时序位置编码。使用很小的 LayerScale 初始化（γ=10⁻⁵），使从 WT-O 检查点冷启动时单帧输入（T=1）严格复现静态行为，仅随着微调逐渐学习时序耦合。

**输出/效果：** 推理 T=1 时 = WT-O 行为；T>1 时学习帧间几何一致性。WT-D 在 Obj.-Val（CD-L2 0.0034 vs 次优 0.0142）和 Truebone（0.0063 vs 次优 0.0120）上大幅超越基线，ActionBench 上仅次于 ActionMesh（该方法输出格式恰好对齐其 GT 的跟踪动画面）。

### 11. 训练与模型变体 (Sec 3.3, 3.4, App B)

**模型变体：** 三个变体共享表示、流匹配损失、深度填充、冻结图像编码器和结构化注意力，仅在尺度归一化和时序块上不同：
- **WT-O（物体静态）：** L=6，z-score 归一化，504×504 训练
- **WT-S（场景静态）：** L=6，log-median 归一化，场景数据训练 + 单层RGBD混合训练
- **WT-D（动态物体）：** 从 WT-O 初始化，追加时序注意力块，50K 迭代微调

**训练设置：**
- **编码器：** 冻结 MoGe ViT-L（仅训练特征投影）
- **解码器：** 48 pre-norm DiT 块，宽度 D=1536，24 头注意力
- **训练阶段：** 物体模型两阶段——196×196 低分辨率 100K 迭代 → 504×504 高分辨率 100K 迭代
- **优化器：** AdamW，lr=1e-4，cosine decay，2000 warmup，weight decay 0.01
- **设备：** 64 H100 GPU，每GPU batch=2，gradient accumulation=4，有效 batch=512
- **推理：** 20步 flow ODE 去噪

**数据：**
- 物体：~300K物体（Objaverse-XL, Objaverse, 3D-FUTURE, Toys4k, GSO, TrueBones），~17M渲染视图
- 场景：3D-FRONT + 内部场景集
- 动态：~16.8K动画资产（Objaverse-XL动画子集 + TrueBones骨骼绑定角色）
- 渲染：随机光照、视角和内参
- 混合训练：WT-S 还消费12个单层RGBD数据集（ScanNet v2, MegaDepth, BlendedMVS, ArkitScenes, Waymo等）

**鲁棒轮廓：** 训练时抖动 alpha 边界，新暴露/缺失像素为伪标签区域，用填充几何目标以降低权重监督，提高对不完美输入掩码的鲁棒性。

**自洽内参恢复：** 用预测的第0层点云最小二乘拟合投影方程恢复 K，使下游（物体插入、新视图合成）无需已知内参。

### 12. 混合训练 (Mix-Training Across Multilayer and Single-Layer Supervision) (Sec 3.5)

**输入/目的：** 先前的单图像深度模型只能从单一监督信号训练——深度估计器只有单层，图生3D模型需要完整3D几何。目标是让同一模型同时从合成3D资产（多层）和真实RGBD图像（单层）学习。

**原理：** 引入标志位 b_single ∈ {0,1} 表示样本是否仅有可见表面监督。在损失掩码 A 中沿层轴门控，单层样本仅计算 L0 的损失。

**公式：**
A^(ℓ) ← A^(ℓ) · (1 - b_single · 𝟙[ℓ≥1])
即 b_single=1 时，ℓ≥1 的层损失被屏蔽；b_single=0 时所有层都被监督。

**输出/效果：** 一个 WT 模型可同时在多层3D资产渲染和单层RGBD数据上联合训练。适用于真实成像数据的可见表面精度显著提升（App E.3 Table 6）。这突破了先前模型要么只能处理合成渲染（LaRI）、要么只能处理可见表面（MoGe）的局限。

---

### 13. 下游应用 (Sec 5)

WT 输出的是相机空间、像素对齐的多层3D点云且可恢复内参，因此下游应用只需轻量、无需再训练的组合逻辑：

1. **文本驱动的3D场景编辑：** WT-S 预测原场景 + WT-O 预测编辑物体，两者同在相机帧且共享像素对应，可直接组合（无需优化循环）。支持物体插入、删除、替换和组合编辑。

2. **几何引导的新视点视频合成：** WT提供完整的几何记忆，沿目标轨迹光栅化直接生成密集多视图深度引导（遮挡区域已有几何支持）。比单层深度图好——后者一旦相机移动，新暴露区域只能凭空想象。

3. **姿态对齐的TRELLIS混合：** 将WT预测的点云体素化作为TRELLIS Stage 1的稀疏结构（不重新训练TRELLIS），保留TRELLIS的纹理和网格解码器，替换其姿态无关的Stage 1。WT-O*（混合）在可见表面MAE（0.0326 vs 次优0.0478）和完整几何Chamfer距离上大幅超越TRELLIS.2及VGGT引导的混合基线。
