# Surflo: Consistent 3D Surface Flow Model with Global State

## 论文概览

### 1. 问题与背景

**解决的问题**：从任意数量未定位（unposed）RGB 图像中重建场景的 3D 几何表面。

**现有方法的不足**：

- **Per-view 方法**（如 VGGT、DUSt3R）：每张输入图像独立预测一个点图（pointmap），输出 token 数量随输入视图数线性增长，点图之间重叠且不对齐，难以融合为干净一致的网格。
- **Global-latent 方法**（如 NOVA3R）：虽将场景压缩为单一隐向量，但只能解码固定数量（如 10K）的低分辨率点，无法按需灵活调整输出密度。
- **Per-scene 优化方法**（如 3D Gaussian Splatting）：需要数百张带位姿的图像，每场景优化耗时长（数十分钟到小时级），不适合快速迭代。

**核心洞察**：3D 几何在视角变换下不变——多张图像是对同一 3D 状态的冗余编码。正确的中间表示应该是单一全局状态（global state），而非 per-view 或 per-pixel 的表示。

### 2. 方法 — 核心思路

Surflo 提出三阶段管线：

1. **编码器**：基于冻结的 VGGT 骨干，将可变数量（N 张）未定位 RGB 视图压缩为固定大小的 K 个隐式 token（K=128），构成全局状态 z。
2. **流匹配解码器**：以全局状态 z 为条件，将任意数量的噪声点（从源分布采样）独立地传输到 3D 表面，输出带法向的定向表面点。
3. **推理时引导**：为抑制独立逐点解码导致的局部不一致性，在 ODE 积分后期注入光度梯度（photometric gradient），通过可微渲染损失关联邻近点。

**关键创新**：
- 首个将**全局隐式状态**与**任意分辨率解码**结合的 feed-forward 方法
- 使用**流匹配**（flow matching）独立传输每个查询点到表面，解码复杂度与点数线性相关
- **渲染引导**（rendering-based guidance）在不改变训练过程的前提下，在推理时抑制离群点

### 3. 效果

- 在 8 个 3D 重建基准上匹配或超越现有 feed-forward 方法，在 Chamfer Distance 和 F1-score 上全面领先
- 比 per-scene 优化方法（如 Gaussian Wrapping）快一个数量级（秒级 vs 分钟级）
- 支持从 8K 到 1M 点的可变分辨率解码，同一隐向量可同时服务快速预览和高精输出
- 在极稀疏视角（2 views）下仍能生成连贯表面，增加视图逐步补全细节

### 4. 局限

- 纹理退化区域（低纹理、反射表面）仍然存在重建质量下降
- 引导步骤（M=32 次梯度更新）带来额外推理开销（30 秒到 3 分钟）
- 依赖 VGGT 作为冻结骨干，未联合优化编码器前端的表示能力
- 未处理输入图像之间的光照/曝光差异，可能影响光度梯度的准确性

## 技术拆解

### 编码器：从图像到固定尺寸全局状态

**输入/目的**：接收 N 张未定位 RGB 图像，输出一个与 N 无关的固定尺寸隐向量 z ∈ R^{K×D}（K=128, D=512）。

**原理**：

1. **VGGT 骨干**（冻结）：对每张输入图像 I_n，VGGT 输出每层的 patch token 和 camera token。从第 4、11、17、23 层提取 patch token，拼接后投影到工作维度 D=512。每视图得到 4×N_p 个 token（N_p = 740 个 patch）。
2. **3D 位置编码**：读取 VGGT 点图中 patch 中心的 3D 坐标 p_n，用高斯傅里叶特征 γ(p_n) 编码并加到 patch token 上。这一步很关键——它让解码器的查询点能通过与编码器相同的 γ 变换，在 cross-attention 中通过空间邻近性定位相关信息，而不需要学习编码器-解码器坐标系的对齐。
3. **压缩（Perceiver）**：用 K 个可学习的隐式查询 token z_p^{(0)}，通过交替 cross-attention（与所有 patch token）和 self-attention，迭代 L_e=4 轮，将 N×4N_p 个 token 压缩为 K 个 token。camera token 也经类似但更轻量的 Perceiver 压缩为 1 个 token z_c。

**关键公式**：

```
z_p^{(l+1)} = SelfAttn^{L_s}( CrossAttn( z_p^{(l)}, {T_n + γ(p_n)}_n ) )  ∈ R^{K×D}
```

迭代 L_e 次后得到最终 z_p，与 z_c 拼接：z = [z_p, z_c] ∈ R^{(K+1)×D}。

**输出/效果**：固定尺寸的全局状态 z，包含场景几何信息（来自 patch tokens）和全局场景信息（来自 camera tokens）。输出大小不随输入视图数 N 变化。

---

### 流匹配解码器：独立逐点表面解码

**输入/目的**：给定全局状态 z 和 P 个查询点 {x_t^{(m)}} ∈ R^3 × S^2（3D 坐标 + 单位法向），预测每个查询点的速度，使其从噪声分布传输到表面分布。

**原理**：

1. **流匹配框架**：采用线性插值路径。训练时采样目标 x_1 ~ p_1（真实表面点）、源 x_0 ~ p_0（噪声分布）、时间 t ~ LogitNormal(1, 1.6)，构造插值点 x_t = (1-t)x_0 + t x_1。
2. **解码器架构**：12 层 transformer。前 6 层：cross-attention（与 z_p）+ MLP，均用 AdaLN 条件化（时间 t 的 sinusoidal 编码 + camera token z_c）。后 6 层：仅 AdaLN + MLP（不再 cross-attend 到隐向量）。**没有逐点 self-attention**——所有点独立处理，空间信息共享完全由编码器隐向量承担。
3. **源分布**：不从标准高斯采样，而是从以 VGGT 点图加噪声后的混合高斯采样。这使初始点集中在几何附近，避免模型能力浪费在空空间，同时留出填充遮挡区域的余地。

**关键公式**：

训练目标（标准流匹配损失）：
```
L_FM(θ, φ) = E[ || v_θ(x_t, t | z) - (x_1 - x_0) ||_2^2 ]
```

推理时用欧拉求解器积分：
```
dx_t/dt = v_θ(x, t, z),    从 t=0 到 t=1
```

**输出/效果**：P 个定向表面点。所有 P 个查询共享同一个 z，解码器相对较小（12 层 transformer），因此可以在单 GPU 上批处理 10^3 ~ 10^6 个点。同一隐向量既支持快速粗预览（8K 点），也支持密集表面（1M 点）。

### 推理时引导：光度梯度耦合逐点解码

**输入/目的**：上述独立逐点解码有一个固有缺陷——邻近点之间没有显式约束，遮挡区域容易出现离群点和不一致。引导机制在 ODE 积分后期（t ≥ 0.95）注入可微渲染梯度来关联邻近点。

**原理**：

1. 在 ODE 的每一步，先用当前速度预测估计 x_1（≈ 真实表面点位置）。
2. 将当前所有估计点实例化为 3D 高斯溅射（Gaussian Splatting），渲染到输入视角得到 RGB 图像。
3. 计算渲染图像与真实输入图像之间的光度损失 L_photo（可选加单目深度损失 L_depth）。
4. 对每个点的估计位置计算 ∇L，反传梯度调整估计位置，从而修正速度预测。

**核心机制**：

```
Step 1: x̂_1 = x_t + (1-t) · v_θ(x_t, t | z)         // 从当前点估计终点
Step 2: x̂_1^{(adj)} = x̂_1 - ∇L_render(x̂_1)          // 梯度调整（M 步）
Step 3: v_g = (x̂_1^{(adj)} - x_t) / (1 - t)          // 调整后取新的速度
```

**关键细节**：
- 引导仅在 t ≥ 0.95 时启动（点已接近表面，梯度信号可靠）
- 每步 ODE 做 M=32 次梯度更新
- 渲染使用 3D Gaussian Splatting（快速、可微、视图数无关）

**输出/效果**：
- 不需要引导：已能取得高精度，但可见离群点噪声
- 光度引导：抑制离群点，恢复更细的几何细节
- 光度 + 单目深度引导：进一步锐化几何边缘
- 代价：增加 30 秒 ~ 3 分钟推理时间（取决于 M）

### 消融实验关键发现

| 组件 | 设置 | 效果（DL3DV CD↓） |
|------|------|-------------------|
| 隐向量大小 | K=32 → K=128 | 0.0089 → 0.0073 |
| 3D 位置编码 | 无 → 傅里叶特征 | 0.0083 → 0.0073 |
| 源分布 | 纯高斯 → VGGT 混合高斯 | 0.0088 → 0.0073 |
| 引导 | 无 → 光度引导 | F1 提升（但有 CD 权衡） |

**引导的双刃剑**：光度引导提升视觉质量和部分指标（如 DeepBlending F1: 70.96→75.09），但在一些基准上 Chamfer Distance 略升（如 DL3DV: 0.0072→0.0083）。这是因为引导倾向于将点拉到可见表面附近，可能会稍微偏离 ground truth 几何。但总体视觉质量收益更大。

### 效率对比

| 方法 | 推理时间（相同场景） | 输入视图需求 |
|------|-------------------|------------|
| VGGT（编码） | ~秒级（单前向） | 可变的 2~N |
| Surflo 解码 100K 点 | 数秒（+引导额外 30s~3min） | 同 N 张 |
| 2DGS / Gaussian Wrapping | 数十分钟 | ≥100 张带位姿 |
| NOVA3R | 秒级 | 固定 2 张，固定 10K 点输出 |

Surflo 的核心效率优势：编码一次后，隐向量可重复用于任意数量的查询点，解码成本与输入视图数无关。
