# GS-2M: Material-aware Gaussian Splatting for High-fidelity Mesh Reconstruction

# GS-2M: Material-aware Gaussian Splatting for High-fidelity Mesh Reconstruction — 深度阅读报告

## 论文概览

### 1. 问题与背景

**解决什么问题：** 从多视角照片中重建高保真三角网格（triangle mesh）。这是一项核心的 3D 视觉任务，传统上依赖多视角立体视觉（MVS），但难以处理高反光（镜面/光滑）表面。

**之前的方法有何不足：**

- **神经隐式方法**（NeRF-based）：如 NeuS、Neuralangelo，重建质量高但训练时间极长（小时级），计算资源需求大。
- **神经显式方法**（3DGS-based）：如 2DGS、PGSR、GausSurf，训练快（分钟级）且实时渲染，但缺乏对表面外观的建模，遇到高反光/镜面表面时产生畸变的非水密网格（见下图）。

![现有 SOTA 方法对反光表面重建的失败案例](https://arxiv.org/html/2509.22276v2/figures/sota-reflective.jpg)

*图：2DGS、GOF、PGSR 等方法在 Shiny Blender 数据集上对反光物体的重建结果——因缺乏外观建模，网格出现严重变形或空洞。*

- **材料分解方法**（如 GS-ROR²、Ref-GS）：虽然能分解材质属性，但依赖于 SDF 主干网络、编码器-解码器等神经组件，推理速度受限且难以规模化。

### 2. 方法 — 核心思路

GS-2M 的核心洞见：**将材料分解与网格重建统一为联合优化框架，用少量可学习参数替代复杂的神经组件。**

关键设计：

1. **在 PGSR 基础上构建**：继承 unbiased depth rendering 和多视角一致性约束，保持 SOTA 重建质量。
2. **引入材料参数**：为每个 3D 高斯体增加两个可学习属性——albedo（反照率 aᵢ ∈ ℝ³）和 roughness（粗糙度 ρᵢ ∈ [0,1]），通过基于 Cook-Torrance 微表面模型的 PBR 渲染管线联合优化。
3. **提出多视角粗糙度监督策略**：利用 NCC（归一化互相关）衡量不同视角间 patch 的光度变化，以此监督粗糙度的学习——高光度变化（反光区域）应赋予低粗糙度，低变化（漫反射区域）赋予高粗糙度。**完全不需要神经组件。**
4. **改进多视角一致性**：增加遮挡感知滤波（显式检测无效对应点）和多视角法线一致性约束。

### 3. 效果

| 数据集 | 指标 | GS-2M | 对比 SOTA |
|--------|------|-------|-----------|
| DTU (15 场景) | Chamfer Distance ↓ | 0.53 (Ours) / 0.51 (w/o BRDF) | PGSR 0.52, GausSurf 0.52 |
| DTU (NVS) | PSNR ↑ | 33.86 (Ours) / 34.22 (w/o BRDF) | PGSR 33.33 |
| TnT Barn | F1 ↑ | 0.57 (w/o BRDF) | PGSR 0.66 |
| TnT Truck | F1 ↑ | 0.67 (w/o BRDF) | PGSR 0.66 |

- 在 DTU 数据集上与 SOTA 显式方法持平，在部分场景甚至超越。
- 在反光表面上（Shiny Blender）**显著优于** 2DGS、GOF、PGSR 等方法，能生成水密且光滑的三角网格。
- 训练时间约 51 分钟（完整版）/ 22.4 分钟（无 BRDF 版），远快于神经隐式方法（数小时）。

### 4. 局限

1. **反照率和光照欠约束**：联合优化中反照率和环境光的分解仍不充分，存在噪声伪影。
2. **自反射无法处理**：对于场景内物体间的相互反射（如 Toaster 场景），当前 Cook-Torrance 模型不够。
3. **Metallic 近似不精确**：当前简单设置 metallic = 1 - roughness，对某些场景不成立。
4. **无界场景 OOM**：自适应密度控制在大场景中生成过多高斯体导致显存溢出。
5. **仅适用于以物体为中心的场景**：PBR 管线设计依赖于物体级受控光照。

## 技术拆解

### 一、Unbiased Depth Rendering（无偏深度渲染）

**输入：** 3D 高斯体的位置 μᵢ、缩放 sᵢ、旋转 Rᵢ，相机参数。

**目的/原理：** 传统 3DGS 用相机空间 z-blending 做深度，导致邻近像素共享相近 z 值（即使真实深度不同），产生有偏深度。GS-2M 采用平面深度（plane depth）：将每个高斯体视为一个微小平面，用高斯体法线方向上的平面距离代替 z 值。

![无偏深度渲染对比](https://arxiv.org/html/2509.22276v2/figures/unbiased-depth.jpg)

*图：左为 z-depth 训练的深度和法线（有偏、噪声大），右为 plane depth（精确、一致）。*

**关键公式：**

- 法线分配：取缩放最小轴对应的旋转矩阵列向量作为法线 nᵢ
- 距离值：d̄ᵢ = μ′ᵢ · (Rᵢ nᵢ)，其中 μ′ᵢ 是变换到相机空间的高斯中心
- 无偏深度图：
  D(p) = D̄(p) / (N(p) · (K⁻¹ p̃))
  其中 D̄ 是 α-blending 融合的距离图，N 是法线图，K 是相机内参，p̃ 是像素的齐次坐标

**输出/效果：** 精确的无偏深度图 D 和法线图 N，用于 TSDF 融合生成高质量网格。

### 二、多视角一致性增强

**输入：** 参考视图和邻居视图的深度图、法线图、RGB 图像。

**目的/原理：** PGSR 使用了多视角几何损失（重投影误差）和光度损失（patch 匹配），但在高频纹理区域约束不足。GS-2M 做了两项改进：

1. **多视角法线一致性**：在参考视图和邻居视图的世界空间采样点的法线方向差异作为额外损失项，提升高频区域的几何一致性。
2. **遮挡感知滤波**：显式检测无效对应——将参考视图像素反投影到邻居视图的相机空间，比较其 z 坐标与邻居深度图的深度值，不一致的像素被排除在损失计算之外（相比 PGSR 用重投影噪声阈值更可靠）。

![多视角一致性与遮挡滤波](https://arxiv.org/html/2509.22276v2/figures/multi-view-pgsr.jpg)

*图（上）：无效对应滤波——p₂ 因深度不一致被排除；图（下）：多视角法线一致性约束示意。*

**输出/效果：** 更鲁棒的多视角几何约束，在 TnT 和 DTU 上均有提升。

### 三、材料建模与 PBR 渲染

**输入：** 每个高斯体的反照率 aᵢ ∈ ℝ³、粗糙度 ρᵢ ∈ [0,1]。无偏深度图 D、法线图 N。

**目的/原理：** 将表面外观分解为漫反射和镜面反射成分。采用 Cook-Torrance 微表面 BRDF 模型，通过延迟渲染（deferred rendering）在图像空间合成 PBR 图像。

**渲染公式（BRDF）：**

fᵣ(ωᵢ, ωₒ) = (1-m)·a/π + D·F·G / [4(n·ωₒ)(n·ωᵢ)]

- a: 反照率（albedo），m: metallic（金属度，m = 1 - ρ）
- D(ρ, θₕ): 法线分布函数（GGX/Trowbridge-Reitz），控制微表面法线朝向 h 的概率
- F: Fresnel 项（Schlick 近似），描述入射角对反射率的影响
- G: 几何项（自遮挡/掩蔽）

**关键公式：**

D(ρ, θₕ) = ρ² / [π(cos²θₕ(ρ²−1) + 1)²]

- ρ 越小（越光滑）-> D 在 θₕ 接近 0 时更集中 -> 高光更锐利
- ρ 越大（越粗糙）-> D 分布更平坦 -> 高光更弥散

**光照建模：** 用可微分环境 cubemap 捕获环境辐射，预滤波到不同 mip 级别：
- 漫反射组分：从 base level 采样（不依赖视角）
- 镜面反射组分：采用 Karis 的 split-sum 近似，分解为预滤波 cubemap 采样 + BRDF 响应 LUT 查询

**输出/效果：** PBR 图像 Ī（合成渲染图），可用 L_pbr 损失与真实图 I 对比，监督所有材料参数。

### 四、多视角粗糙度监督（核心创新）

**输入：** 参考视图和邻居视图的 RGB 图像。

**目的/原理：** 训练仅用 L_pbr 损失极度欠约束，会导致光照噪声、反照率污染。以往工作靠神经编码器/预训练先验解决。GS-2M 提出**基于多视角光度变化的粗糙度监督**：

关键观察：**高反光区域在不同视角下外观变化剧烈（光度变化大），漫反射区域光度稳定。**

![多视角粗糙度监督策略](https://arxiv.org/html/2509.22276v2/figures/mv-rough.jpg)

*图：通过 NCC 损失量化光度变化，用阈值 λ_ref 判断区域是否为反光表面，进而奖惩对应的粗糙度值。*

**流程：**
1. 对参考视图的每个像素 p，在邻居视图中找到对应 patch（利用已有的多视角投影）
2. 计算 warp 后 patch 的 NCC 损失 L_NCC——衡量光度变化程度
3. 低 NCC（高变化，反光区域）-> 惩罚高粗糙度（鼓励低粗糙度）
4. 高 NCC（低变化，漫反射区域）-> 惩罚低粗糙度（鼓励高粗糙度）

**损失函数 L_ro 的效果：**

![消融实验：有无粗糙度监督的对比](https://arxiv.org/html/2509.22276v2/figures/mv-ro-ablation.jpg)

*图：上排（无 L_ro）——光照噪声大、反照率被高光污染；下排（有 L_ro）——粗糙度正确，分解清晰。*

**输出/效果：** 粗糙度参数被有效监督，消除对神经组件的依赖，保持 PBR 分解质量。

### 五、完整训练管线

**训练过程分两阶段：**

1. **引导阶段（前 5,000 次迭代）**：仅优化几何参数，损失为 L_rgb + L_plane + L_alpha（若有 mask）。用于初始化高斯体。
2. **联合优化阶段（最多 30,000 次迭代）**：全部损失激活，L_rgb 替换为 L_pbr。

**总损失函数：**

L = L_plane + L_alpha + L_dn + L_mv + L_tv + L_sm + L_ro + L_pbr

- L_plane: 惩罚非平面高斯体（sᵢ 的最小值）
- L_dn: 深度-法线一致性（以图像梯度加权）
- L_mv: 多视角几何+光度一致性（含法线一致性 + 遮挡滤波）
- L_tv: 法线总变分损失（以粗糙度为权重的平滑正则化）
- L_sm: BRDF 参数平滑损失
- L_ro: 粗糙度监督（核心创新）
- L_pbr: PBR 渲染与真实图的 L₁ + SSIM 损失

**网格提取：** 训练完成后，从所有视角渲染 RGB-D 图像，通过 TSDF 融合（Open3D）+ marching cubes 提取最终三角网格。

### 六、核心消融与局限拆解

**消融结果：**

| 配置 | DTU CD ↓ | DTU PSNR ↑ |
|------|----------|------------|
| 无法线一致性 | 0.58 | 26.73 |
| 无遮挡滤波 | 0.53 | 33.76 |
| 完整版 | 0.53 | **33.86** |

法线一致性是最大提升来源，遮挡滤波主要提升 NVS 质量。

**局限拆解：**

![自反射场景失败案例](https://arxiv.org/html/2509.22276v2/figures/limit-self.jpg)
*Toaster 场景——Cook-Torrance 无法处理间接光照（自反射）。*

![金属度近似问题](https://arxiv.org/html/2509.22276v2/figures/limit-metallic.jpg)
*汽车白色条纹本应是金属，却被近似为电介质——metallic 需要独立学习。*

1. **反照率/光照欠约束**：当前仅有粗糙度有专门监督，反照率和环境光分离不够干净。方向：类似 L_ro 的自监督策略。
2. **无间接光照**：不支持光线追踪，无法建模相互反射。方向：引入 ray-based 方法。
3. **Metallic 近似**：m = 1 - ρ 是硬编码近似，需要独立可学习参数。
4. **无界场景**：3DGS 的 ADC 在背景细节丰富场景产生过多高斯体 → OOM。方向：引入 adaptive densification 改进。

## 总结

GS-2M 的创新在于**用极简的材料参数 + 多视角光度变化先验**，在 3DGS 显式重建框架中统一了网格重建和材料分解两个任务。其主要优势是：不依赖任何神经组件/预训练先验，保持快速训练（~51 分钟）的同时，既能处理漫反射表面达到 SOTA，又能良好应对高反光表面。核心代价是 PBR 延迟渲染带来的加倍训练时间（22min → 51min），以及对物体中心场景的适用性限制。
